Documentation · Loading screen

Loading screen for your script

Wide in-game loading bars while LuaMore authenticates and delivers your script. Pick a preset when creating a script, paste the Luau, set your loader URL.

Start 4 loading presets Loader URL How it works Don't Need help?

Quick start

Create a script

Add it in the dashboard and pick a loading screen preset (or none).

Copy the Luau

Take the matching preset from the four below.

Set the loader URL

Paste your loader URL from the dashboard into LOADER_URL.

Run it

Insert as a LocalScript — the bar shows while LuaMore loads your script.

Keys stay in the loader URL from your dashboard — this is not a key-entry box. Leave KEY empty for keyless scripts.

copy usage snippet 
-- Pasteable loader from dashboard (use the dashboard-generated URL; it carries a signed load marker)
_G.script_key = "YOUR_KEY"
loadstring(game:HttpGet(
	"https://www.luamore.win/v1/load/YOUR_PROJECT_ID?e=1&script=YOUR_SCRIPT&lsig=SIGNED_MARKER&key=" .. _G.script_key .. "&_cb=" .. os.clock(),
	true
))()

Loader URL

Where Dashboard → Scripts → your project → copy the loader for the script. Keyed scripts include ?key=... in the URL.
Keyless Use the keyless loader URL — the same loading overlay works without a key parameter.

How it works

The preset builds a ScreenGui, shows the bar, runs loadstring(game:HttpGet(LOADER_URL))(), then dismisses the overlay. If the load fails, check the output for the error — the preset warn()s it for you.

usage.lua 
-- Pasteable loader from dashboard (use the dashboard-generated URL; it carries a signed load marker)
_G.script_key = "YOUR_KEY"
loadstring(game:HttpGet(
	"https://www.luamore.win/v1/load/YOUR_PROJECT_ID?e=1&script=YOUR_SCRIPT&lsig=SIGNED_MARKER&key=" .. _G.script_key .. "&_cb=" .. os.clock(),
	true
))()

Don't

  • Hardcode license keys in your game — use the dashboard loader URL.
  • Skip the loader and try to HttpGet the script directly. Delivery won't work.
  • Point LOADER_URL at someone else's project. The signed load marker won't match.
